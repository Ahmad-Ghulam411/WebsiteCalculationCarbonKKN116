# Folder Gambar (assets)

Letakkan **dua berkas gambar** berikut di dalam folder ini agar tampilan
website memakai logo & foto asli Kota Parepare:

| Nama berkas (harus persis)   | Isi gambar                                   |
| ---------------------------- | -------------------------------------------- |
| `logo-parepare.png`          | Logo / lambang Kota Parepare (kiri atas)     |
| `latar-parepare.jpg`         | Foto pemandangan Kota Parepare (latar hero)  |

## Catatan
- **Nama berkas harus sama persis** (huruf kecil semua) seperti tabel di atas.
- Format logo sebaiknya **PNG transparan**, ukuran ± 200×200 piksel.
- Format latar sebaiknya **JPG** lebar (mis. 1600×1000 piksel) agar tetap ringan.
- Bila kedua berkas ini **belum ada**, website tetap tampil rapi:
  - Logo akan diganti otomatis oleh **emblem SVG bawaan**.
  - Latar akan memakai **gradien hijau–biru** bawaan.

Cukup unggah/timpa berkas di sini — tidak perlu mengubah kode apa pun.
